# Kingslayer
An indie card-based roguelike game


# BOSS 数值

数值：分为基础，倍率和修正

+ 基础：J Q K BOSS 的基础数值 (正整数)
+ 倍率：分为花色倍率和类型倍率 (正数)
+ 修正：分为花色修正和类型修正 (整数)
  
计算顺序为：基础\*花色倍率\*类型倍率+花色修正+类型修正

最后向上取整

常规 BOSS 分为 Jack Queen King 三种类型，Spade Heart Diamond Club 四种花色，每个轮回共 12 个

初始设定：

### 血量
+ 类型基础：4/6/8
+ 类型倍率：5.0/5.0/5.0
+ 花色倍率：1.0/1.0/1.0/1.0
+ 全修正： 0

### 攻击力
+ 类型基础：2/3/4
+ 类型倍率：5.0/5.0/5.0
+ 花色倍率：1.0/1.0/1.0/1.0
+ 全修正： 0
  

### 难度

+ Bear：手牌上限+1，所有 BOSS 血量倍率-1，所有 BOSS 攻击力倍率-1
+ Kid: 手牌上限+1，所有 BOSS 血量倍率-1
+ Teen: 手牌上限+1
+ Man: 默认配置
+ Guys: 所有 BOSS 血量倍率+1，所有 BOSS 攻击力倍率+1
+ Sky: 所有 BOSS 血量倍率+1，所有 BOSS 攻击力倍率+1，未降服的 BOSS 不会进入弃牌堆

# 塔罗牌

每张塔罗牌都有正面与负面效果，选择时会同时升级，保证可以持续升级

初始等级为 0，每次升 1 级，记当前等级为 X，就有：

0. 愚者（The Fool，0）
    + 手牌上限+X+1
    + 后续轮回BOSS乱序，每次选择随机花色BOSS攻击力倍率+0.25

2. 魔术师（The Magician，I）
    + 可以打出牌面小于8X+10的连招（J:11 Q:12 K:13）
    + 后续BOSS攻击力基础+2X-1，有1/4概率获得血量+8X+4

3. 女祭司（The High Priestess，II）
    + 弃牌时每张弃牌削弱BOSS 3X的攻击力
    + 弃牌后手牌数量少于X+1时直接失败

4. 女皇（The Empress，III）
    + Q手牌点数+8X
    + Queen攻击力倍率+2X

5. 皇帝（The Emperor，IV）
    + K手牌点数+12X
    + 所有King攻击力倍率+2X,生命值倍率+X,生命值基础+X

6. 教皇（The Hierophant，V）
    + 如果出牌前手中有三种花色，触发第四种花色效果
    + 选择时随机两种花色血量倍率+0.15,攻击力倍率+0.1

7. 恋人（The Lovers，VI）
    + A花色会触发B花色的效果
    + 未失效的A花色BOSS限制B花色效果点数减半触发。

8. 战车（The Chariot，VII）
    + J可以作为侍从牌打出，点数+3X
    + Jack生命值倍率+X，攻击力倍率+X

9. 力量（Strength，VIII）
    + 所有牌点数+X
    + BOSS 血量修正+4X，攻击力修正+2X

10. 隐者（The Hermit，IX）
    + 每次放置1张joker在牌堆顶
    + 选择本牌时25%概率所有BOSS血量基础+2

11. 命运之轮（The Wheel of Fortune，X）
    + 塔罗牌选择数+X+1，最终威力+X
    + 每次选择塔罗牌后随机更改手牌花色

12. 正义（Justice，XI）
    + 捕获BOSS后额外生成X+1张BOSS到弃牌堆
    + 所有BOSS攻击力倍率+X+1

13. 倒吊人（The Hanged Man，XII）
    + 所有BOSS攻击力基础-X，攻击力倍率-X，攻击力修正-6X
    + 手牌槽位-(2X-1)

14. 死神（Death，XIII）
    + 有Max(75,20+5X)%的概率跳过BOSS攻击
    + 所有BOSS攻击力修正+3X

15. 节制（Temperance，XIV）
    + 每回合开始时回洗X张牌并抽取X张牌
    + 红心，方片点数-2X

16. 恶魔（The Devil，XV）
    + 手牌上限-(3X-2)，结算点数-(4X-2)
    + 每回合出牌次数+X

17. 塔（The Tower，XVI）
    +  所有BOSS血量倍率-1.5X，血量修正-8X
    + 结算点数-X

18. 星星（The Star，XVII）
    + 所有方片点数+4X
    + 所有方片BOSS血量倍率+0.25X，攻击力倍率+0.15X

19. 月亮（The Moon，XVIII）
    + 所有梅花点数+4X
    + 所有梅花BOSS血量基础+0.4X

20. 太阳（The Sun，XIX）
    + 所有红心点数+4X
    + 所有红心BOSS攻击力基础+0.15X

21. 审判（Judgement，XX）
    + 如果每次出牌都有对应BOSS花色，击败BOSS后回洗所有弃牌，抽张X+1牌，下一个BOSS攻击力-4X+4"

22. 世界（The World，XXI）
    + 所有黑桃点数+4X
    + 所有黑桃BOSS血量基础+0.2X，攻击力基础+0.2X

# 罪孽

轮回时，BOSS 可能会染上七种不同的罪孽中的一种，获得特殊效果

数量：
+ 轮回1：1
+ 轮回2：1~3
+ 轮回3：2~4
+ 轮回4：3~4
+ 轮回5：3~6
+ 轮回6：4~8
+ 轮回7：6~8
+ 轮回8：6~10
+ 轮回9：7~12
+ 轮回10：10~12
+ 轮回11及以上：12

罪孽类型与效果：

+ 暴食: 玩家出牌数量为1时，获得额外20%攻击力。玩家出牌数量大于1时，造成的伤害与效果为原来的75%
+ 色欲: 回合结束时额外获得初始血量25%的血量，初始攻击力25%的攻击力
+ 忧郁: 回合结束时玩家手中每张人头牌都有33%概率变成随机的同花色非人头牌
+ 怠惰: 有20%概率玩家攻击造成的伤害为0，但是出牌效果正常触发
+ 嫉妒: 复制上一个非嫉妒罪孽 BOSS 的罪孽效果和花色
+ 暴怒: 额外获得%25初始攻击力，回合结束时永久摧毁玩家的随机一张手牌
+ 傲慢: 无法被joker禁用，血量小于0时若未被捕获则额外获得血量绝对值7倍的血量，3倍的攻击力（仅一次）

# 命名约定与目录整理（2026-09）

+ 代码 `.cpp/.h`：PascalCase，文件名 = 类名（`Game.h`、`SceneMain.cpp`）。
+ 全大写缩略词保留全大写：`UI.h`、`CRT.h`。
+ 入口固定小写 `main.cpp`；打包的第三方单头 `json.hpp` 沿用上游文件名。
+ 资源脚本收敛为唯一一对：`Resource.rc` + `resource.h`。
+ 资源 `assets/` 用 snake_case；`lang/` 为语言标签（不在本约定内）。
+ `_obsolete/`：旧代/残留留档（未编译的 `Kingslayer.rc`、`resource1~5.h`、`.aps` 缓存、`RCa33700`、旧 `test/`）。确认无用后可整目录删除。
